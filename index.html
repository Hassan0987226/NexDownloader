How it works

Important
  • Direct file URL: downloads the file itself when the source permits browser access.
  • TikTok / Instagram / Facebook: sends the URL to your configured backend, which must support that public URL and the platform's rules.
  • Audio: MP3 conversion needs FFmpeg installed on the backend host.

GitHub Pages cannot extract social-media videos by itself. Configure the backend URL in app.js and deploy the backend folder to a Python-capable host. No login-only, private, DRM-protected, or access-control bypass.
