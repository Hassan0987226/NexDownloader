NexDownloader — GitHub Pages fixed static version

Upload index.html, app.js, and style.css to the root of your GitHub repository (or replace the existing files). Commit changes and wait for GitHub Pages to rebuild.

Important limitation: GitHub Pages only hosts static files. This version saves direct URLs and opens them at their original source. It cannot run server.js, fetch arbitrary cross-origin files through JavaScript, or extract videos from social-media pages. For those features, deploy the Node.js backend to a server host and configure the frontend API URL.
